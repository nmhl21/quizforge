# QuizForge — paste your notes, get a quiz

QuizForge turns study notes into an interactive multiple-choice quiz and
flashcards, generated by **Gemini via Firebase AI Logic** (cloud, typed JSON
response schema). Built for **SLAY HACKS 2026** (Devpost, $5,000 in prizes).

- Paste lecture notes, a textbook chapter, or any study material.
- Pick the number of questions (5 / 8 / 10) and difficulty (Easy / Medium / Hard).
- Answer one question at a time with instant feedback and explanations,
  then get a score screen with a full review of every answer.
- Flip through AI-generated flashcards covering the key terms.
- Quizzes are saved locally in the browser (max 10), with Markdown / JSON export.

## How it works

- **AI path:** Firebase AI Logic, Gemini Developer API backend
  (`getAI` + `GoogleAIBackend`, `getGenerativeModel` with
  `responseMimeType: "application/json"` and a typed `responseSchema`).
  The model is instructed to base every question only on the pasted notes —
  it never invents facts. Model: `gemini-3-flash-preview`.
- **Demo mode:** add `?demo=1` to the URL to try the full UI without a
  Firebase project. A local simulator builds a real quiz *from your notes*
  ("What is X?" from definitions found in the notes, plus fill-in-the-blank
  questions). Results are clearly labelled "Simulated".

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static dist/ — deploy anywhere (GitHub Pages, Firebase Hosting, …)
```

## Firebase setup (for the real AI path)

1. Create a project at https://console.firebase.google.com.
2. Open **Build > AI Logic** → Get started → choose the **Gemini Developer API** backend.
3. In **Project settings > General**, copy your web app's config into
   `src/firebase-config.js` (or set `VITE_FIREBASE_*` env vars at build time —
   env vars take precedence).
4. Reload and press **Generate quiz**.

No Firebase project? Use `?demo=1` — no account needed.

## Tech

Vite + vanilla JS + firebase@13.4.0 (Firebase AI Logic). No backend server,
no database — everything runs in the browser; history lives in localStorage.
